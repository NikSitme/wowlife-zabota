# Реестр выплат — Забота

Дашборд графика выплат и структуры зарплаты команды заботы wowlife.
Хостинг: GitHub Pages. Данные: Supabase (Postgres). Правки кода вносятся через Claude Code и попадают на сайт после push в `main`.

## Первичная настройка

1. **Supabase.** Создать проект, открыть SQL Editor и выполнить `supabase/schema.sql`.
2. **Ключи.** В Project Settings → API взять Project URL и anon public key, вписать в `config.js`.
   Сервисный ключ (service_role) в репозиторий не класть.
3. **GitHub Pages.** Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`.
4. Открыть сайт. При пустой базе появится окно первого запуска: вставить данные из старого дашборда
   (кнопка «Скопировать данные для переноса» в нём) или начать с исходных.

## Как устроено хранение

- Всё состояние дашборда лежит одной jsonb-записью в таблице `payroll_state` (id = `zabota`).
- Каждое сохранение увеличивает `version`; сохранение с устаревшей версией отклоняется, страница подтягивает данные с сервера.
- Предыдущие версии складываются в `payroll_state_history` триггером, откат: `supabase/rollback.sql`.
- Realtime включён: правки одного пользователя появляются у остальных без перезагрузки.
- Представления `payroll_schedule` и `payroll_month_status` дают строки графика и статусы месяцев для обычного SQL.

## Доступ

Авторизации нет: любой, у кого есть ссылка, видит и правит реестр. Не публиковать адрес в общих чатах.
